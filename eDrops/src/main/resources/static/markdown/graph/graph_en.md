Function plotting

- First run: Default axis limits
- Next: Dynamically calculated min/max limits

Axes are drawn automatically, but you can adjust the limits yourself if you want.

### About the graph module

Parts:
- Input parameters
- Calculate axis
- Draw axis
- Parse math function
- Draw curve from step-by-step function calculations  

Only one variable is allowed. You can select the x-axis variable from the predefined variables.
The function evaluator is based on a custom-built calculator.
You define a function to be used for the y-axis.
Aspect ratio relates to the height versus width of the graph.
Font scale is the relative size for axis numbers.  

In the future, it will be possible to plot multiple curves.
