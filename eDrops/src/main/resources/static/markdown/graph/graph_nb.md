Midlertidig SVG med en sinusbølge.

* Første kjøring: Standard aksegrenser
* Neste: Dynamiske min/maks-grenser

Enkle antakelser for aksestreker og tekster.

### Målet for prosjektet
* Modul for å tegne akser og grafer med SVG (utført)
* Modul for å matematiske funksjoner / RPN basert (har prototype fra tidligere)
* Matematisk funksjon settes inn fra bruker med min og max verder
* Import fra regneark eller API, for eksempel for energiberegninger
* Vurdere å lage data også i databasen for plotting
* Tidsbaserte simuleringer (krever WASM)

Beregninger kjører på backend. SVG brukes for å tegne graf
Klient-side WASM for live-animasjon senere.
Jeg tror at akseprogrammet kan brukes som bakgrunn for WASM animasjon.  

Siden prosjektet er ambisiøst så vil det ta tid å få alt på plass på fritiden. 
Siden dette er på internett, blir feilhåndtering og sikkerhet viktlig.
