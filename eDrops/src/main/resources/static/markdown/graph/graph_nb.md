Plotting av funksjoner

- Første kjøring: Standard aksegrenser
- Neste: Dynamiske beregnede min/maks-grenser

Akser tegnes automatisk, men du kan justere på grensene selv hvis du vil. 

### Om grafmodulen

Deler:
- Input-parametre
- Beregne akse
- Tegne akse
- Parse mattefunksjon
- Tegne kurve basert på trinnvis input og beregning med funksjonen  

Bare én variabel er tillatt. Du kan velge x-aksevariabel blant de forhåndsdefinerte variablene.
Funksjonsregneren er basert på egenutviklet kalkulator.
Du definerer en funksjon som skal brukes for y-aksen. 
Høydeforhold har med høyde kontra bredde på grafen å gjøre.
Font skala er relativ størrelse for aksetall.

I framtiden blir det muligheter for å plotte flere kurver.
